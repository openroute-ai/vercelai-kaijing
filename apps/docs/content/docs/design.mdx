## 三份上游

画布底座已经在 `apps/workspace`，来自 Apache-2.0 上游提交 `174e652451a3533c20462acb7380008428670ff6`。保留创作台、无限画布、素材库、时间线、本机 SQLite、命令内核和 MCP。界面产品名只用开镜。短剧数据挂在现有项目上，不另做一套项目系统。内部类型若仍带上游名字，不在领域阶段为了改名去大范围重命名。

Toonflow（MIT，Vue / Vue Flow）只提供领域语义：剧本和分镜、角色与场景资产、画布节点、生成时用 `@` 点名资产、文档式剧本区、多模型选择。用 React 重写。不引入 Vue 工程。3D 预演、插件市场和全套多语言不做。普通用户的「多模型」是画质档位「快速 / 标准」，供应商由网关映射。

火宝短剧（CC BY-NC-SA 4.0）只对照能力：一句话或小说到剧本、抽取角色场景道具、拆分镜、写生图和生视频提示词、逐镜合成、整集拼接。用开镜自己的命令和提示词实现。禁止复制其源码、提示词原文、技能文件和资源。导演技能由开镜撰写，规定调用顺序，不是外部仓库里的文件。

## 两条路径

普通用户安装客户端后，本机工作台自动打开。没有 `cloud.session_token` 时进入工作台里的云端账户页，调用 `POST /api/v1/cloud/register` 或 `/login`。这两个接口把注册和登录交给 better-auth，cookie 由 `cloud` 实例签发。然后新建本地项目。M1 可以在 `/drama` 手写剧本和分镜并重新打开，不调用模型。点「做一集」仍是后续里程碑：导演在本机按命令顺序编排；生图和生视频走薄云并扣积分；结果下载回本地素材和画布。导出 MP4 到用户选择的目录，不上传。

平台运营登录 `apps/web`，用另一份 better-auth（`web` cookie，`web_auth`）。可以查看云端用户、封禁、调整积分、查看生成任务。不能打开用户的画布，也不能用运营 cookie 调用 `/api/v1/cloud/*`。公开邮箱注册页关闭，这个门禁在 better-auth 插件里。受邀手机号仍通过 better-auth 的手机号插件注册。

协作的三种强度见 `docs/design/collaboration.md`。一期不做。屏幕、操作和状态见 [交互与界面](/docs/ued)，正文在 `docs/ued/`。

未登录、积分不足、供应商失败和修订冲突的处理见 `docs/design/journeys.md`。积分不足时保留已写好的剧本和分镜。

## 数据放哪

| 数据 | 位置 |
| --- | --- |
| 项目、画布坐标、素材、生成谱系、时间线 | 本机 SQLite 和媒体目录 |
| 剧本、角色、场景、道具、分镜、镜头状态 | 同一份 SQLite 的 `drama_*` 表 |
| 账户、积分、生成任务 | Postgres。桌面用户在 public schema，运营在 `web_auth` |
| 成片 | 用户选的本机目录 |
| 供应商密钥 | 只在 `apps/api` 环境变量 |

镜头只保存素材 id。一张图从哪次生成来，沿用现有生成谱系，不在短剧表里再记一遍。云端不建分镜表。

## 命令

短剧命令由界面、内置「做一集」和 MCP 共用。需要改画布或时间线时，调用已经存在的命令内核。

| 命令 | 作用 |
| --- | --- |
| `drama.rewrite_script` | 一句话或小说变成剧本稿 |
| `drama.extract_entities` | 抽取并去重角色、场景、道具 |
| `drama.breakdown_storyboard` | 拆成有顺序的镜头 |
| `drama.write_prompts` | 写每镜的图像和视频提示词，解析 `@` |
| `drama.generate_character_image` | 经网关出角色图，登记为本地素材 |
| `drama.generate_shot_video` | 经网关出镜头视频 |
| `drama.sync_canvas` | 把领域对象投影到画布，不重置用户拖过的坐标 |
| `drama.update_shot` | 只改一镜的说明、对白、时长和引用 |
| `drama.assemble_episode` | 就绪镜头进入时间线，写字幕，导出 MP4 |

「做一集」自动走到视频就绪后停止。导出是单独动作。文本步骤也走网关的 `kind=text`，这样密钥和积分只有一处。

## 薄云合同

生成继续用 `POST /api/v1/generations` 和 `GET /api/v1/generations/{id}`。M4 起必须带 `cloud` 会话。扣费顺序是：余额足够才建任务，写 `hold`，成功再 `capture`，失败则 `release`。同一 `idempotencyKey` 不重复预扣。

`packages/providers` 的 `GenerationProvider` 只有 `submit` 和 `get`。一期各写一个原创的图像适配器和视频适配器。桌面不实现这个接口，也不在普通模式保存供应商密钥。

## 里程碑

| 阶段 | 完成时 |
| --- | --- |
| M0（本 PR，尚未合并） | 画布在 3020 跑起来，桌面壳能加载，`cloud` 与运营登录分开，生成只是排队 |
| M1 | 不调用模型也能保存剧本和分镜 |
| M2 | 一段输入得到结构化剧本和分镜，MCP 能调用同名工具 |
| M3 | 画布上出现短剧节点和 `@` 引用 |
| M4 | 不配 Key 也能出一镜视频，失败退回积分 |
| M5 | 本机导出可播放 MP4 |
| M6 | 安装 → 登录 → 一句话 → 导出。这是一期完成定义 |

一期不做完整浏览器协作工作台、Android、Toonflow 的 3D 预演和插件市场，也不把画布改成 Next.js。仓库根许可保持 LGPL-2.1；`apps/workspace` 单独保持 Apache-2.0。
