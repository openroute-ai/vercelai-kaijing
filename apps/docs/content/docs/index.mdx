开镜（Kaijing）是开源的 AI 短剧 / 漫剧制作工具。仓库是 `openroute-ai/vercelai-kaijing`，平台域名是 vercelai.cn。

## 一期怎么交付

普通用户下载 Windows 或 macOS 客户端，注册登录后就能用。生图和生视频走平台的生成网关，用积分结算，不需要自己申请模型密钥。

工作台跑在用户电脑上。云端只保存账户、积分和生成任务状态，不托管完整项目和成片。

## 仓库里现在有什么

M0 是骨架，不是能出片的产品：

- `apps/desktop`：Electron 壳，开发时打开本机工作台
- `apps/workspace`：Vite + React 欢迎页
- `apps/web` / `apps/api`：登录、积分和生成任务占位
- `packages/drama-core`、`packages/providers`：领域类型和供应商接口

剧本改写、分镜、画布、时间线和真实供应商调用都还没实现。

## 本地运行工作台

```bash
pnpm install
pnpm --filter workspace dev
```

浏览器打开 `http://127.0.0.1:5173`。需要桌面窗口时，另开一个终端执行 `pnpm --filter desktop dev`。
