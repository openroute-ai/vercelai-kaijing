## 屏幕地图

桌面窗口里的顶层是：首页、创作、项目、短剧、云端账户。项目再进入创作台、画布、素材、时间线和该项目的短剧稿。

现在已经能用的是外壳、项目、创作台、画布、素材、时间线、云端账户注册登录，以及 `/drama` 的手写剧本和分镜。`做一集`、`@` 引用、逐镜出片和导出 MP4 按 M2 到 M6 才出现，现在不要画成已经完成。

一期没有只读分享和同时编辑的界面。导出互传以后若要做，也不在这套界面里展开。

运营后台是另一棵导航：薄云总览、用户、邀请、积分、生成任务。侧栏没有项目、画布或短剧。公开邮箱注册关闭。
