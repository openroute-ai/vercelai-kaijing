# 云端账户

路径 `/cloud-account`。桌面用户在这里注册和登录。请求由 better-auth 签发 `cloud.session_token`。这不是 `apps/web` 的运营登录，页面上要写清楚。

开发期工作台把 `/cloud-api` 转到本机 API，cookie 落在工作台源站上。安装包里的窗口同样只访问配置好的薄云，用户不填写 API 地址。

## 1. 屏幕结构

从上到下：

1. 返回开镜（回首页）
2. 标题「云端账户」
3. 一句说明：「用这个账户登录开镜。它和平台运营后台不是同一个登录。」
4. 未登录时是注册 / 登录表单
5. 已登录时是会话卡：名字、邮箱、积分余额、退出
6. 状态行，放本次提交的结果

账户页不承担「做一集」。现在代码里若还有「提交一条排队任务」的输入框，那是网关占位，产品界面不把它当作生成入口。生成从短剧面板发起，见 [drama.md](drama.md)。

## 2. 未登录：登录

默认是登录，不是注册。

| 字段 | 规则 |
| --- | --- |
| 邮箱 | 必填，去首尾空白后转成小写再提交 |
| 密码 | 必填。不在输入框下逐条展示校验规则，错误放在状态行 |

主按钮「登录」。次按钮「没有账户？注册」，只切换到注册表单，不跳转。另有「刷新会话」，用于已经有 cookie、页面还显示未登录时再问一次。

### 状态

| 状态 | 界面 |
| --- | --- |
| 空 | 邮箱和密码为空，主按钮可点。点下后若为空，状态行「请填写邮箱和密码」 |
| 提交中 | 主按钮变为「正在登录…」，表单不可重复提交 |
| 成功 | 表单换成会话卡。状态行「登录成功」 |
| 失败 | 留在登录表单，密码清空，邮箱保留。状态行「账号或密码错误」。不区分邮箱是否存在 |
| 网络失败 | 留在表单。状态行「暂时连不上云端，本机项目还在。」提供「重试」 |

## 3. 未登录：注册

从登录用次按钮切过来。多一个「名字」字段，可空，空则用邮箱。

密码规则在提交前检查，不通过就不打到 better-auth：至少 8 位，含大写、小写、数字和符号。不通过时状态行：「密码至少 8 位，并包含大小写字母、数字和符号」。邮箱不像邮箱时：「请填写邮箱」。

主按钮「注册」。次按钮「已有账户？登录」。

| 状态 | 界面 |
| --- | --- |
| 空 | 三个字段为空 |
| 提交中 | 「正在注册…」 |
| 成功 | 进入已登录会话卡，并已经有积分账户。状态行「注册成功」。余额显示 0 |
| 邮箱已占用 | 留在注册。状态行使用接口返回的说明，不自动切到登录，免得用户以为自己已经进去了 |
| 网络失败 | 与登录相同 |

注册成功后不跳去运营后台，也不强制进入某个项目。用户用「返回开镜」或顶栏离开。

## 4. 已登录

会话卡：

- 名字 · 邮箱
- 「积分余额」加数字。注册后是 0。数字来自当前会话，不让用户在输入框里改
- 主按钮没有第二个。次按钮「退出」「刷新会话」

余额为 0 时不要画成错误。说明一句：「还没有积分。生成会在以后使用积分，现在仍可在本机写剧本和分镜。」M4 之前没有充值按钮。充值如果要加，只从运营后台发放，不在这一页做支付。

退出成功：回到登录表单，状态行「已退出」。本机项目列表不变。

刷新会话：

| 结果 | 界面 |
| --- | --- |
| 仍有效 | 更新余额，状态行「已登录」 |
| cookie 没了 | 回到登录表单，状态行「尚未登录」 |

## 5. 会话过期

用户停在画布、短剧或项目页时，下一次需要云端的请求发现会话没有了：

- 不整页替换成登录表单
- 当前页顶部提示：「登录已过期，本机项目还在。」
- 主按钮「去登录」，打开 `/cloud-account` 并落在登录
- 正在输入的剧本和分镜留在表单里。用户回来后可以再保存

只读本机数据（打开项目、看画布、看已保存的短剧）不因为过期被挡住。

## 6. 和运营登录的差别

这一页不提供手机验证码、邀请码、封禁或角色。那些在 [admin.md](admin.md)。若有人把运营后台的 cookie 带到这个源站，刷新会话的结果仍是「尚未登录」，不显示运营身份。
