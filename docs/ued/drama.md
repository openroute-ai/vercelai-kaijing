# 短剧

短剧挂在已有项目上。列表在 `/drama`，某一集的稿在 `/drama/$projectId`。M1 只做手写剧本和分镜：不调用模型，关掉窗口再打开仍在。导演、`@`、出片和导出分阶段出现，不能提前画成已经完成。

## 1. 列表 `/drama`

标题「短剧」。说明：「在本机写下剧本和分镜。这一步不调用模型。」

主按钮「新建短剧项目」。它创建一个普通本地项目，名字默认「未命名短剧」，然后进入 `/drama/$projectId`。不创建第二种项目。

次按钮「刷新项目列表」。列表每一项是项目名，主操作是打开该项目的短剧稿。

| 状态 | 界面 |
| --- | --- |
| 尚未刷新 | 列表为空，不显示「出错」。用户可先点新建 |
| 加载 | 「正在读取项目…」 |
| 空 | 「还没有项目。」主按钮仍是新建 |
| 有数据 | 名字列表。没有短剧稿的项目也列出，打开后是空稿 |
| 失败 | 「项目列表没有读出来。」「重试」 |

从顶栏「短剧」进来的就是这一页。从某个项目的表面切换进来则直接是编辑页，不先回列表。

## 2. 编辑页 `/drama/$projectId`（现在）

标题「手写剧本和分镜」。返回链「返回短剧列表」。

页上只有一份当前稿。没有多稿切换。保存后 `revision` 增加，页上写「当前稿 revision N」。

字段从上到下：

| 字段 | 控件 | 现在的规则 |
| --- | --- | --- |
| 集标题 | 单行 | 可空，过长则不能保存 |
| 来源 | 下拉「一句话」「小说」 | 对应 `one_liner` / `novel` |
| 原始输入 | 多行 | 用户的原话，改剧本正文时保留 |
| 剧本正文 | 多行 | 分段纯文本。可先空着，只保存分镜 |
| 分镜标题 | 单行 | 默认可写「分镜」 |
| 每一镜 | 描述、对白、时长 | 描述必填才算一镜。对白可空。时长默认 4000 毫秒，非法则整单不保存 |
| 加一镜 | 次按钮 | 在末尾加一镜空行。空描述在提交时丢掉，不单独报错 |
| 保存到本机 | 主按钮 | 剧本和分镜一次提交 |

打开页面时先读本机。状态行：

| 状态 | 文案 |
| --- | --- |
| 加载 | 「正在读取本机稿…」表单先不可编辑 |
| 没有稿 | 「还没有剧本，写下后保存」 |
| 已有稿 | 「已打开第 N 稿」，字段填上标题、来源、原文、正文、分镜和每一镜 |
| 保存中 | 「正在保存…」主按钮不可重复点 |
| 保存成功 | 「已保存第 N 稿」，revision 换成新的数字 |
| 校验失败 | 留在表单。状态行写出原因，例如「第 2 镜缺少描述」或「第 1 镜时长无效」。已填内容不清空 |
| 找不到项目 | 「找不到项目。」主按钮「返回短剧列表」 |
| 读取失败 | 「读取失败。」「重试」 |

保存不要求登录，不显示积分，不出现模型进度。关掉应用再打开同一地址，字段与上次成功保存一致。只停在内存里、没点保存的修改会丢失，离开页面前若表单脏了，见 [export-and-failures.md](export-and-failures.md)。

现在不要放这些控件：画质、做一集、角色 / 场景 / 道具卡、`@`、提示词、生成、放到时间线、导出 MP4、分享。

## 3. M2 才出现的「做一集」

M2 在编辑页主操作区增加「做一集」，手写「保存到本机」降为次按钮。做一集旁边是集标题（沿用现字段）、来源、原始输入，以及画质「快速 / 标准」，默认标准。

主按钮在 M2 的完成定义是停在提示词就绪，不是出片。按钮下方的进度只列出文本步骤：剧本、角色场景道具、分镜、提示词。每步完成可展开结果。用户能改剧本、改名字、删一镜，再从该步继续。

| 状态 | 界面 |
| --- | --- |
| 未开始 | 主按钮「做一集」 |
| 进行中 | 标出当前步骤，其余步骤不可点成完成 |
| 该步成功 | 结果写入表单，revision 增加。用户可以改完再保存 |
| 没有识别到角色 | 角色区写「没有识别到角色」，不自动进入生视频 |
| 模型失败 | 不写入半截稿。进度停在失败步骤，主按钮变为「从这里继续」 |
| 未登录就做需要云端的步骤 | 打开云端账户。已经写好的稿留在本机 |

M2 的进度条不要出现「角色形象」「逐镜视频」「导出」。那些步骤的格子从 M4、M5 再显示。M4 之前「做一集」的结束文案是「提示词已就绪」，不是「成片已完成」。

角色、场景、道具在 M2 以三张列表出现在剧本下方：名字、说明。主操作是改名字和说明。没有「生成形象」按钮，直到 M4。

## 4. M3 的 `@` 和画布

M3 在镜头和提示词里支持 `@`。输入 `@` 后浮层列出本项目的角色和素材，选择后插进文本。浮层空态：「还没有可引用的角色或素材。」

同一页增加次按钮「在画布上查看」。它打开该项目画布，不把短剧页换成画布。画布上能看见剧本、角色和镜头卡。用户在画布上拖动之后，回到短剧页再保存分镜，不得把卡片位置重置。

短剧页仍是改正文和镜头描述的地方。画布上的拖动不反向改剧本。

## 5. M4 的出片

M4 给角色加「生成形象」，给镜头加「生成视频」。两者都是次按钮，主按钮仍是「做一集」或「从这里继续」。

点生成时若未登录，去云端账户，镜头状态不变。若积分不足，该镜显示「积分不足」，状态保持 `prompted` 或 `failed`，剧本和分镜仍可编辑。供应商失败时该镜显示「这一镜没有生成」，主操作「只重试这一镜」。成功后缩略图来自本机素材，不长期指向云端临时地址。

进度里这时才出现「角色形象」和「逐镜视频」。

## 6. M5 和 M6 的导出入口

M5 在短剧页底部增加主操作「放到时间线」，把就绪镜头送进现有时间线并写字幕。未就绪的镜头列出来，不静默跳过。然后时间线页提供「导出 MP4」，细节见 [export-and-failures.md](export-and-failures.md)。

M6 不改短剧页结构。变化在窗口外面：用户从安装包进来，首启提示指向云端账户，导出仍写到用户选的本机目录。
