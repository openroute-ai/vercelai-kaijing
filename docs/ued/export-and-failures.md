# 保存位置、导出和失败

开镜一期的成片和项目都在用户这台电脑上。薄云只保留账户、积分和生成任务。这一页把「文件落在哪」和跨屏幕的失败规定在一起，避免每个屏幕各写一套。

## 1. 什么放在本机

| 用户以为的「保存」 | 实际位置 | 界面怎么说 |
| --- | --- | --- |
| 项目、画布、时间线、素材 | 本机工作台数据目录 | 「保存在这台电脑上」 |
| 剧本和分镜 | 同一份本机库里的短剧表 | 「已保存第 N 稿」 |
| 导出的 MP4 | 用户在系统对话框里选的目录 | 「已写入你选择的文件夹」 |
| 积分和登录 | 薄云 | 只在云端账户和运营后台出现 |

不要把「保存到云端」做成默认主按钮。不要在导出成功后自动上传 MP4。

M5 之前，界面上没有「导出 MP4」。文档和线框可以标出它的位置，但不能做成可点的完成态。

## 2. 导出 MP4（M5 起）

入口在时间线，不在运营后台，也不在云端账户。

1. 用户点「导出 MP4」。
2. 系统保存对话框。默认文件名用项目名，用户可以改目录和文件名。
3. 导出进行时，时间线仍可看，主按钮变为「正在导出…」，不可再开第二个导出。
4. 成功：状态「已写入你选择的文件夹」，并给出「在文件夹中显示」。文件不出现在云端任务列表。
5. 取消对话框：没有任何状态变化，不记成失败成片。

| 失败 | 文案 | 结果 |
| --- | --- | --- |
| 本机没有可用的编码工具 | 「这台电脑还不能导出视频。」 | 不登记已完成的成片 |
| 磁盘满或目录不可写 | 「没有写入你选择的文件夹。」 | 不留下半截文件当作成功 |
| 时间线上没有可导出的片段 | 「时间线上还没有可导出的画面。」 | 不打开保存对话框 |

只把一份 MP4 交给别人，是文件复制，不是产品里的分享功能。接收方不能靠这个文件继续改剧本。项目包的导入导出还没做，一期界面不放「分享项目」或「导入项目包」。那是 [协作设计](../design/collaboration.md) 里最小的一档，本套界面不展开它的屏幕。

## 3. 未保存和修订冲突

手写短剧、画布和时间线各自保存，不共用一个「全部保存」。

离开当前表面时，若表单或时间线有未保存修改：

- 标题「还有没保存的修改」
- 主按钮「保存」
- 次按钮「不保存并离开」「留下」
- 保存失败则不离开，并显示该表面自己的错误

命令内核返回修订冲突时：

- 文案「这次没保存，内容已被另一次编辑更新。」
- 主按钮「重新载入」
- 次按钮「留下我这边的修改」
- 不自动用后一次覆盖前一次
- 不把冲突解释成登录失败

短剧手写保存是整稿提交。冲突若发生在同一稿的 revision 上，重新载入后显示磁盘上的那一稿，状态行写明新的 revision。用户留下的修改只存在于表单，再次点保存才写入。

## 4. 登录和积分

这些失败不清除本机稿。

| 情况 | 出现在哪 | 界面 |
| --- | --- | --- |
| 未登录就点生成或「做一集」里需要云端的步骤 | 当前页顶部，不替换成整页登录 | 「登录后才能生成。」主按钮「去登录」。手写稿还在 |
| 密码错误 | 云端账户 | 「账号或密码错误」 |
| 会话过期 | 当前页顶部 | 「登录已过期，本机项目还在。」 |
| 账户被封禁（M4 起调用生成） | 当前生成步骤 | 「这个云端账户已停用。」本机项目仍可打开。不提供自行解封 |
| 积分不足 | 该镜头或该次生成 | 「积分不足。」镜头不全都标失败。已写的剧本和分镜可继续编辑。没有充值按钮 |
| 供应商失败 | 该镜头 | 「这一镜没有生成。」主操作「只重试这一镜」。积分按云端规则退回，界面只说明「积分已退回」或保持余额刷新，不让用户手改余额 |
| 云端不可达 | 当前云端动作 | 「暂时连不上云端，本机项目还在。」 |

积分数字只在云端账户展示给桌面用户，精确到已有的余额字段。生成过程中的预扣不在 M1 出现。M4 起，余额在一次生成开始后变为预扣后的数，失败再恢复。恢复前不要显示成负数。

## 5. 本机数据坏了

读不到 SQLite 或媒体目录时，项目列表和短剧页用同一句：「读不到这台电脑上的开镜数据。」主按钮「重试」。不提供「从云端恢复项目」，因为云端没有项目副本。

不要把这个状态画成空项目。空项目的意思是库打开了、里面没有条目。
