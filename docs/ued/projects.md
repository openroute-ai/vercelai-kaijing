# 首页和项目

项目是本机的。新建、打开、删除都不上传到薄云。短剧稿、画布和时间线挂在同一个项目上，不另做一种「短剧项目」。

## 1. 首页 `/`

首页回答「这是开镜」并给出两条去路。

主按钮「开始创作」，去 `/studio`。次按钮「打开项目」，去 `/projects`。第三条文字链接「写短剧」，去 `/drama`。

未登录且用户曾经选过「先在本机看看」时，在按钮下方放一条提示「登录后才能生成。」，主按钮去云端账户，不挡住创作和项目。第一次打开且还没有做过这个选择时，窗口停在云端账户，不先画首页。已登录时不显示这条提示。

首页不列出全部项目。最近如果有项目，最多显示 3 条，每条的主操作是「打开」。没有项目时这块不出现，避免和空的项目页重复。

## 2. 项目列表 `/projects`

标题「项目」。说明：「项目保存在这台电脑上。」

主按钮「新建项目」。次按钮没有批量云同步。列表里每条可以删除，删除是危险操作，不放在主按钮上。

每条显示：名字、最近活动时间。有封面时用封面，没有封面时用纯色块，不请求云端图片。

点一条的主操作「打开」：进入该项目上次使用的表面。没有记录时进入创作台 `/studio/$projectId`。同一条上的次操作：

| 次操作 | 去向 |
| --- | --- |
| 画布 | `/canvas/$projectId` |
| 时间线 | `/editor/$projectId` |
| 短剧 | `/drama/$projectId` |

短剧次操作始终可点。没有短剧稿时，编辑页是空稿，不是 404。

### 状态

| 状态 | 界面 |
| --- | --- |
| 加载 | 列表区「正在读取本机项目…」，新建按钮仍可点 |
| 空 | 「还没有项目。」主按钮「新建项目」 |
| 有数据 | 卡片或表。打开是每条的主按钮 |
| 读取失败 | 「读不到本机项目。」次按钮「重试」。不建议用户去登录，因为列表不依赖云端 |
| 删除确认 | 「删除后，这个项目的画布、时间线和短剧稿会从这台电脑移除。」主按钮「删除」，次按钮「取消」 |
| 删除成功 | 条目消失。若删的是当前唯一项目，回到空状态 |

删除不调用薄云，也不影响积分。

## 3. 新建项目

从项目页或创作台进入。字段只有名字，默认「未命名项目」。工作模式沿用现在的创作台 / 画布选择，不新增「短剧模式」这个第三种项目类型。

主按钮「创建」。创建成功后进入该项目的创作台，并在页内提供「去写短剧」链接到 `/drama/$projectId`。

| 状态 | 界面 |
| --- | --- |
| 提交中 | 「正在创建…」 |
| 成功 | 进入项目 |
| 失败 | 留在表单。「项目没有创建。」次按钮「重试」 |

名字只做展示。短剧集标题在短剧页另存，不自动覆盖项目名，除非用户在项目设置里自己改。

## 4. 打开已有项目

打开不要求登录。项目不存在时（链接里的 id 失效）：整页「找不到这个项目。」主按钮「回到项目列表」。不自动新建一个同名项目。

从短剧、画布、时间线互相跳转时带同一个 `projectId`。浏览器后退回到离开前的表面，不重置对方的未保存编辑。未保存怎么处理见 [export-and-failures.md](export-and-failures.md)。
