# 创作台、画布、素材和时间线

这些表面已经在本机工作台里，品牌用开镜。短剧不替换它们，也不把它们搬进运营后台。一期一个人使用，屏幕上没有协作者。

从项目打开时，页头显示项目名，旁边四个表面切换，当前项不可再点：

| 切换 | 路径 |
| --- | --- |
| 创作台 | `/studio/$projectId` |
| 画布 | `/canvas/$projectId` |
| 素材 | 该项目的素材视图 |
| 时间线 | `/editor/$projectId` |
| 短剧 | `/drama/$projectId` |

「短剧」用文字链放在这一排的末尾，避免和画布工具抢主按钮。

## 1. 创作台

创作台是现在的提示和生成工作面。页头是项目名。

现在的主操作保持创作台已有的生成入口（选模型、写提示、运行）。它服务图像和视频草稿，不是短剧导演。短剧的「做一集」不放在这里，避免两个主按钮抢同一句话。

| 状态 | 界面 |
| --- | --- |
| 空项目 | 提示区为空，说明「从这里创作，或去短剧写剧本。」链接到该项目的短剧页 |
| 加载 | 项目名位置「正在打开…」，工具先不可点 |
| 找不到项目 | 与项目页相同的「找不到这个项目」 |
| 运行中 | 主按钮进入进行中，禁止连点。失败时结果区说明原因，不清空提示词 |
| 成功 | 结果进入本机素材，可再放到画布 |

未登录时，创作台仍可打开和编辑本机内容。真正要打到薄云的运行，按 [export-and-failures.md](export-and-failures.md) 把人带到云端账户。M4 之前，短剧路径不从创作台扣积分。

## 2. 无限画布

画布是这个项目的卡片和连线。主操作是已有的添加卡片、移动、连线。没有「分享画布」。

空画布：中央「还没有卡片。」次操作「从素材添加」和「去短剧」。不自动铺满示例图。

加载：画布区域用骨架，不闪一下空状态再填上。读取失败：「画布没有打开。」主按钮「重试」。重试失败不新建空画布盖掉原文件。

M3 之前，短剧不会往画布上生剧本卡、角色卡和镜头卡。不要在现在的空状态里画这些卡的占位。M3 起这些卡由 `drama.sync_canvas` 放入，用户拖过的位置在再次同步时保留。画布上的改动不写回剧本正文，除非用户回到短剧页保存。

`@` 引用不在现在的画布工具条上。M3 起，生成前提示里输入 `@` 打开本项目素材和角色名的选择，选中后记下素材 id。选择层是浮层，关闭后画布坐标不变。

## 3. 素材

素材是本机文件。列表显示缩略图、类型（图 / 视频 / 音频）、加入时间。

主操作「打开」。次操作「放到画布」。删除要确认：「从本项目移除这件素材？时间线上已使用的片段会失去来源。」

| 状态 | 界面 |
| --- | --- |
| 空 | 「这个项目还没有素材。」 |
| 加载 | 网格骨架 |
| 失败 | 「素材列表没有读出来。」「重试」 |
| 文件丢了 | 条目还在，缩略图位置写「文件不在本机」。不向云端重新要，除非该素材本来就是一次生成下载，且本机下载从未成功 |

云端任务返回的视频必须先落到本机媒体目录，素材库只认这份文件。链接过期不是素材丢失。

## 4. 时间线

时间线编辑已有片段：裁切、移动、字幕。主操作沿用现有编辑，不新造一套时间线。

空时间线：「还没有片段。」次操作「从素材添加」。M5 之前没有「从短剧镜头铺到时间线」。那个动作是 `drama.assemble_episode`，按钮文案「放到时间线」，放在短剧页而不是时间线的空状态里，避免时间线在 M1 就出现一个不能用的主按钮。

修订冲突：若保存时命令内核返回冲突，时间线顶部提示「这次没保存，时间线已被另一次编辑更新。」主按钮「重新载入」，次按钮「留下我这边的修改」（留下是只留在内存里，再次保存前要看清差异）。导演和 MCP 不能静默覆盖用户刚改的时间线。冲突时不弹运营或登录。

加载失败与画布相同，不把空时间线写成成功保存。
